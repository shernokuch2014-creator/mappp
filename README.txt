ShoxCraft - Yangi Yil plagini
=============================
Komanda:  /yangiyil   (ruxsat: shoxcraft.yangiyil, odatda faqat OP)

Nima qiladi:
 - Alohida "shoxcraft_yangiyil" dunyosini yaratadi (asosiy dunyoga tegmaydi)
 - Qorli tekislik, yolkalar, qor odamlar, sovgalar, chiroqlar, markaziy platforma quradi
 - Gologrammalarni o'zi yaratadi (ShoxCraft, Yangi yil bilan, yangi yilgacha sanoq)
 - Komandani qayta yozsangiz eski dunyoni o'chirib, yangisini quradi

O'rnatish:
 1) mvn clean package  ->  target/ShoxCraftYangiYil.jar
 2) Jarni serverdagi plugins papkasiga tashlang
 3) Serverni qayta yoqing
 Talab: Paper/Spigot 1.20+, Java 17+
